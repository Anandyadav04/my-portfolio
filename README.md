## 🛠 Tech Stack & Tools

### Frontend & Styling
* **Core:** React 18 & TypeScript (for strong type safety)
* **Styling:** Tailwind CSS (for modern utility-first styling) & CSS Variables
* **Components:** Custom interfaces inspired by shadcn/ui (Radix UI primitives)
* **Animations:** Scroll reveal transitions (`use-scroll-reveal.ts`) & fluid CSS animations

### Backend & Integrations
* **Contact Form:** Interactive submission using **@emailjs/browser**
* **Form Validation:** Validated dynamically using **React Hook Form** + **Zod** schema validation
* **Notifications:** Responsive toast updates powered by **Sonner**

## 💻 Local Setup & Development

To run this project locally, make sure you have [Node.js](https://nodejs.org/) installed, and then follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Anandyadav04/my-portfolio.git
   cd my-portfolio
   ```

2. **Navigate to the application subdirectory:**
   ```bash
   cd Anand-yadav
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```
   *The site will be active locally at `http://localhost:5173`.*

5. **Build for production:**
   ```bash
   npm run build
   ```
